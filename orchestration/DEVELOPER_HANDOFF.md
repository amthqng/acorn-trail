# Developer Agent handoff

This manual pilot starts with one child-review Actions run and **one finding selected by the product owner**.

1. Complete **Child experience and education review** and obtain its run ID from the Actions run URL.
2. Review the downloaded child-review report. Choose a single well-defined finding to investigate.
3. Under **Actions → Developer proposal handoff → Run workflow**, enter that run ID and your selected finding.
4. The workflow downloads the report from GitHub Actions, invokes **Developer Agent → Independent Technical Reviewer**, and uploads a `developer-handoff` artifact containing `handoff.md`.
5. Read the proposal and review. The next step is an explicit separate authorization for any implementation.

GitHub Actions launches the process and handles the artifact. `developer-handoff.ts` implements agent sequencing and report handoff.

## Safety
- Read-only permissions to repository and Actions. Agents have no tools to edit files or open PRs.
- Input report is generated by a prior AI run and must not be treated as verified child observation or certified curriculum evaluation.
- User input authorizes drafting and reviewing **only**, not code changes.
- No game source edits, commits, deployments, or automatic merges.
- The source excerpt is not a full code audit.
- Each manual run invokes two model responses and may incur API charges.
